1. NON-AFFILIATION DISCLAIMER

Auto Launcher is an independent software application developed and published exclusively by Psycho Labs. Auto Launcher is not sponsored by, endorsed by, or affiliated with Google LLC, Android, or the official Android Auto platform.

2. OVERVIEW & NATURE OF THE APP

Auto Launcher is designed to provide an organized, high-visibility launcher interface optimized for in-vehicle smartphone use. It allows users to access navigation tools, audio controls, and phone shortcuts through large, driver-friendly touch targets.

3. DATA ACCESSED & PERMISSIONS REQUESTED

Depending on features enabled by the user, Auto Launcher may request access to:

A. Installed Application Querying (QUERY_ALL_PACKAGES)

  • Purpose: Because Auto Launcher functions as an app launcher / home utility, it queries the Android PackageManager to identify installed applications so the user can choose which apps to place on their automotive home screen.
  • Usage & Storage: The list of installed apps is read strictly on-device in real time. Your installed app inventory is never uploaded, shared, or transmitted to any external server.

B. Location Data (GPS)

DEVELOPER ACTION REQUIRED — SPECIFY LOCATION STATUS:
Choose Option A or Option B below and remove the other before publishing:

[OPTION A — IF LOCATION IS NOT USED:]
Auto Launcher does not request access to fine or coarse device location. No GPS or vehicle speed data is tracked.

[OPTION B — IF SPEEDOMETER / TRIP STATS ARE USED:]
If enabled for real-time speedometer display, Auto Launcher accesses device location (ACCESS_FINE_LOCATION) solely while in the foreground to calculate current ground speed. Speed and coordinates are displayed live on-screen and are not logged, transmitted, or shared remotely.

C. Notification Access / Media Session (Optional)

  • Purpose: If the user opts into media controls, Android's NotificationListenerService or MediaSessionManager may be used to display current track titles and playback controls (play/pause/skip).
  • Usage: Metadata is used strictly to render playback controls on the dashboard. No message contents or personal notification texts are stored or transmitted.

6. DATA RETENTION & DELETION

Custom dashboard layouts, favorite app shortcuts, and user preferences are saved locally on your device in standard Android storage. When you uninstall Auto Launcher or clear the app's cache and data, all local configurations are permanently wiped from the device.

7. DATA SECURITY

All application operations execute within standard Android app sandboxes. We do not maintain any cloud databases storing driving patterns, location telemetry, or user usage history.

8. SAFE DRIVING NOTICE

Auto Launcher is intended to reduce distraction through simplified interfaces. Users remain solely responsible for operating their vehicle safely and complying with all local traffic laws regarding mobile device use while driving.
